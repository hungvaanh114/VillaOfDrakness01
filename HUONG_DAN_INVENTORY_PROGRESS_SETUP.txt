2. SCRIPT MOI DA TAO
============================================================

Inventory:

- ItemData.cs
  ScriptableObject data cho item.
  Field quan trong:
  id, itemName, description, icon, itemType, canStack, maxStack, canUse, keyID, worldPrefab, heldPrefab.

- InventoryItem.cs
  Data runtime cho item trong inventory: ItemData + Amount.

- InventoryManager.cs
  Quan ly danh sach item, add/remove/use/equip.
  Event:
  OnInventoryChanged, OnItemAdded, OnItemRemoved, OnItemSelected, OnItemUsed, OnItemEquipped.

- InventoryUI.cs
  Tu build UI fullscreen overlay:
  Hanh Trang / Nhat Ky / Manh Not Nhac.
  Dieu khien:
  TAB mo/dong, Q/E doi tab, ESC dong.
  Chuot trai chon, chuot phai hoac double-click dung/trang bi.

- InventorySlotUI.cs
  UI slot item. Xu ly click chuot.

- HeldItemController.cs
  Tim LeftHandProp/LeftHand de cam item tren tay trai.
  Neu chua co hold point thi tao ItemHoldPoint duoi root tay trai.
  Spawn visual cua key/item dang equip.

- ItemPickup.cs
  Component gan len prefab item world.
  Implement IInteractable de PlayerInteract nhat item bang E.

Journal:

- JournalEntryData.cs
  ScriptableObject cho entry nhat ky.

- JournalManager.cs
  Quan ly danh sach entry.

Music:

- MusicSheetData.cs
  ScriptableObject cho manh not nhac.

- MusicSheetManager.cs
  Quan ly music sheet da thu thap.
  Field quan trong:
  requiredMusicSheetCount.
  Khi CollectedMusicSheetCount >= RequiredMusicSheetCount thi MusicSheetCompleted = true.

- MusicSheetPickup.cs
  Component gan len prefab music sheet world.
  Music sheet khong vao grid Inventory thuong.

Piano:

- PianoPuzzle.cs
  Logic kiem tra melody.
  Mac dinh melody:
  C, D, E, F, G

- PianoPuzzleUI.cs
  Popup UI piano o giua man hinh.
  Co 7 phim trang: C D E F G A B.
  Click phim dan hoac bam keyboard C/D/E/F/G/A/B se phat note tuong ung.
  Co phim den trang tri.
  ESC dong UI.

- PianoInteractable.cs
  Gan len object Piano.
  Neu chua du ban nhac: hien "Ban chua co du ban nhac."
  Neu du: mo PianoPuzzleUI.

Quest:

- GameProgressManager.cs
  Quan ly progression:
  Start, EnteredVilla, ExploringVilla, CollectingMusicSheets, PianoUnlocked, PianoCompleted.

Editor Setup:

10. LUU Y KHI MO RONG
============================================================

- Khong doi ten class/script/field cu dang duoc scene reference.
- Khi them item moi:
  1. Tao ItemData moi.
  2. Gan icon/mo ta/type.
  3. Tao prefab world co ItemPickup.
  4. Gan ItemData vao ItemPickup.

- Khi them key moi:
  1. Tao ItemData itemType = Key.
  2. Dat keyID, vi du: BasementKey.
  3. DoorSystem.requiredKeyID phai trung chuoi BasementKey.

- Khi them music sheet moi:
  1. Tao MusicSheetData moi.
  2. Them vao MusicSheetManager.sheets.
  3. Tang RequiredMusicSheetCount neu can.
  4. Tao prefab co MusicSheetPickup.

- Khi doi melody Piano:
  Mo PianoPuzzle component va sua requiredMelody.
  Mac dinh hien tai: C D E F G.

- Khi lam save system sau nay can luu:
  Inventory item id + amount.
  Equipped item id.
  Collected musicSheetID.
  Door unlocked state.
  MusicSheetCompleted.
  GameProgressManager.CurrentProgress.

11. CAC FILE CAN KIEM TRA NEU CO LOI
============================================================

Khong mo duoc Inventory:

- Kiem tra InventoryUIRoot co InventoryUI.
- Kiem tra InputSystem_Actions co Inventory = Tab.
- Kiem tra EventSystem trong scene.

Khong click duoc UI:

- Kiem tra Canvas co GraphicRaycaster.
- Kiem tra EventSystem co InputSystemUIInputModule.
- Kiem tra Cursor hien khi Inventory open.

Khong nhat duoc item:

- Prefab phai co Collider.
- Prefab phai co ItemPickup hoac MusicSheetPickup.
- PlayerInteract phai dang sendRaycast = true.
- Item nam trong interactRange.

F khong bat den:

- InputSystem_Actions phai co UseFlashlight = Keyboard F.
- PlayerInput phai dung action asset nay.
- ItemUsageSystem phai co itemLantern, lantern, _light, _lanternCanvas.
- Item_Flashlight phai duoc add vao InventoryManager startingFlashlight.

Door khong mo bang key:

- Key ItemData.keyID phai trung DoorSystem.requiredKeyID.
- Key phai duoc equip, khong chi nam trong inventory.
- DoorSystem.isLocked = true.

Piano khong mo:

- MusicSheetManager.RequiredMusicSheetCount phai dung.
- Can collect du so sheet.
- Piano object phai co PianoInteractable va Collider.
- Canvas phai co PianoPuzzleUIRoot va PianoPuzzleUI.
